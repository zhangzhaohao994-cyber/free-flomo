# 验收记录

日期：2026-10-18（北京时间）。环境为本机桌面 Chromium、Node.js 24.16、SQLite、独立临时后端，以及 Vercel + Turso 公网部署。所有笔记、账号、图片与微信消息均为专门的测试数据。

- `npm run check`：独立 HTML JavaScript、后端模块语法通过。前端没有外链 JavaScript/CDN。
- `npm test`：7 组测试通过，覆盖账号/令牌、不同用户的数据隔离、同步冲突、删除墓碑、MCP读写接口、登录失效、来源限制、无模型/语音配置的明确错误、微信明文/AES验签与重复消息去重。
- AI SDK 工具循环通过模型夹具测试：只能搜索当前用户；生成的保存提案不直接写入数据库。**不是实际模型质量验收。**
- 核心浏览器流程 25 项通过：新增、刷新、草稿、标签、搜索、置顶、编辑、引用、回收站、图片、统计、导出导入、两个页面并发保存、手机宽度布局、主题等。
- 后端扩展界面 13 项通过：账号独立空间、两个独立浏览器存储经后端双向同步、文字历史与恢复、明确区分本地文字关联、每日回顾、地图节点、无模型错误、锁屏/刷新恢复及账号退出后的本地空间隔离。
- 导入与离线 5 项通过：ZIP 相对路径图片还原、CSV 引号及换行、未知日期标记、条件导出、断网重开和断网新增后刷新恢复。
- 实际下载文件另行读取核对：完整 JSON 和 HTML 各4条且含原图；筛选后的JSON恰好1条，文字与图片符合筛选；新的浏览器空间能从下载文件重新导入。

- 公网接口 12 项通过：登录、关闭公开注册、未登录拒绝访问、GitHub来源CORS、拒绝其他来源、3.3MB图片格式载荷分片上传/下载与完整往返、永久删除墓碑、未配置服务的明确错误。
- 公网浏览器 15 项通过：双端双向同步、历史恢复、回顾规则和标签前缀置顶同步、锁屏与退出隔离，页面异常为0。
- 真实PNG跨公网 6 项通过：1000×1000测试图、分片上传下载、两个独立浏览器的图片内容逐字符一致且能实际解码。另确认重新部署后的函数仍能读取Turso中的原有笔记。
- DeepSeek官方接口最小调用通过：服务端直连 `deepseek-flash`，真实返回“连接成功”，用量14 tokens；API Key未写入前端或仓库。

- DeepSeek完整浏览器流程11项通过：并行大图片同步、真实问答及来源引用、工具保存提案不自动写入、确认保存、所选笔记洞察、记忆档案生成及Turso读取、实际Markdown下载，页面异常为0。模型测试仅基于4条专用测试笔记，不代表大库记忆或长期质量验收。

机器可读的浏览器结果见 `browser-results.json`。图片素材为一像素测试图片，非真实用户素材。390px宽度检查仅为桌面浏览器仿真，不代表真实iPhone/微信/Safari已验收。
