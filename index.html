笔记属于你

免费浮墨是独立实现的本地笔记工具，与 flomo 官方无关联。无需注册，独立 HTML 可本地使用；连接自托管后端后可登录同步，并在服务器配置模型后启用 AI。不同账号使用独立本地空间。

导出备份

JSON 是完整备份，包含图片、历史版本、置顶、引用和回收站，能重新导入。HTML 可离线阅读；Markdown 仅导出文字和标签。默认导出全部，也可以勾选仅导出当前筛选结果。

导入笔记

支持 JSON/HTML、含原图的 flomo ZIP、CSV、Markdown 和文本。CSV 可识别日期/正文列，兼容部分 Day One 导出。保留已有笔记，重复记录自动跳过。flomo HTML 仅导入文字、标签和内嵌图片，不会抓取外链图片，ZIP 内的本地图片会按相对路径读取；未适配的 Apple 专用导出会明确报错。

锁屏保护

防止临时借用设备时被直接看到。仅界面锁，不加密本地数据库。刷新或离开超过一分钟后自动锁定。

留住一闪而过的想法

直接写，按「记下来」保存。标签放在哪里都可以，例如 #读书 或 #读书/随想。点击父标签能看到所有子标签里的笔记。

支持 **加粗**、*斜体*、以 > 开头的引用、以 ## 开头的小标题，以及 - [ ] 待办。链接自动变为可点击文字。卡片右上角可编辑、置顶或删除；删除后可在回收站恢复，不自动清空。
