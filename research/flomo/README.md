## 边界

官方披露、历史自述、研究推断与未知分别标明。当前付费人数、营收、净利润、现金余额及完整股权和团队名册未核实；音频仅阅读节目说明，未做全量听校。人员仅收集职业相关公开信息，不收录私人联系方式、家庭资料、私聊或敏感身份信息。未完成的核验不写成“无异常”。

只保存摘要与链接，不全文转载或镜像付费内容。研究文字由本次检索整理；来源版权归原权利人。仓库根目录的软件 MIT 许可证不代表取得第三方材料或商标的授权。没有调用 flomo 私有接口，也没有改变原笔记应用。
