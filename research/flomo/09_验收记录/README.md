# 验收范围

本地检查包含内部链接、54 条来源元数据、12 篇分类资料、ZIP 读取与逐文件 SHA-256、桌面及手机尺寸 Chromium 的 25 项交互检查。`browser-results.json` 保存 Playwright 实际返回的结果。

真实 iPhone、Safari、微信浏览器、flomo 登录后的产品功能、会员支付、经营财报与工商司法穿透都未由这些页面检查验证。

资料 ZIP 包含分类正文、来源卡片、数据索引、合订稿、独立 HTML、构建模板和脚本；不包含浏览器截图与此处的验收日志。验收日志单独放在 GitHub 文件目录，以避免文件清单及资料包自我引用。

页面无外部脚本、字体、统计或用户输入上传。原笔记应用文件未改动，只新增 `research/flomo/`。
